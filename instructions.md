## Запуск проекта

Для запуска проекта необходимо перейти в корневую директорию приложения.

### Стандартные способы запуска

Проект может быть запущен с использованием стандартных команд `npm`, предназначенных для различных платформ:

- `cd bills-subscriptions`
- `npm run android`
- `npm run ios`
- `npm run web`

---

### Запуск в эмуляторе iOS

Для запуска приложения в эмуляторе iOS рекомендуется использовать автоматизированный скрипт:

- `./start.sh`

Скрипт выполняет следующие действия:

- проверяет, что запуск осуществляется из директории `bills-subscriptions`;
- очищает кеш Expo;
- запускает приложение и автоматически открывает iOS Simulator.

---

### Запуск тестов

Для выполнения автоматизированного тестирования используется отдельный скрипт:

- `./test.sh`

Скрипт:

- проверяет корректность текущей директории;
- очищает экран терминала;
- запускает тесты с использованием фреймворка Jest.
