## Основные сущности приложения

В приложении используются следующие основные сущности, обеспечивающие локальное хранение данных о платежах, подписках и категориях расходов.

---

### Category

Сущность `Category` предназначена для классификации платежей и подписок.

| Поле      | Тип данных | Описание                           |
| --------- | ---------- | ---------------------------------- |
| id        | string     | Уникальный идентификатор категории |
| name      | string     | Наименование категории             |
| color     | string     | Цвет категории (HEX, опционально)  |
| icon      | string     | Иконка категории (опционально)     |
| createdAt | datetime   | Дата создания                      |
| updatedAt | datetime   | Дата последнего изменения          |

---

### PaymentEntry

Сущность `PaymentEntry` описывает разовый платёж или регулярную подписку.

| Поле       | Тип данных | Описание                                      |
| ---------- | ---------- | --------------------------------------------- |
| id         | string     | Уникальный идентификатор записи               |
| title      | string     | Наименование платежа или подписки             |
| amount     | number     | Сумма платежа (в минимальных единицах валюты) |
| currency   | string     | Валюта платежа (например, `USD`, `EUR`)       |
| type       | enum       | Тип записи (`bill` / `subscription`)          |
| categoryId | string     | Идентификатор категории                       |
| dueDate    | date       | Дата ближайшего платежа                       |
| repeatRule | string     | Правило повторения (для подписок)             |
| note       | string     | Дополнительное описание (опционально)         |
| isPaid     | boolean    | Признак оплаты (для разовых счетов)           |
| createdAt  | datetime   | Дата создания записи                          |
| updatedAt  | datetime   | Дата последнего изменения                     |

---

### PaymentOccurrence (опционально)

Сущность используется для хранения истории фактически совершённых платежей.

| Поле    | Тип данных | Описание                    |
| ------- | ---------- | --------------------------- |
| id      | string     | Уникальный идентификатор    |
| entryId | string     | Ссылка на `PaymentEntry`    |
| amount  | number     | Фактически оплаченная сумма |
| paidAt  | datetime   | Дата и время оплаты         |

---

## Связи между сущностями

- `Category` **1 : N** `PaymentEntry`
- `PaymentEntry` **1 : N** `PaymentOccurrence` (опционально)
