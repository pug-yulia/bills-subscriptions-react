## Функциональные требования

Приложение предназначено для локального управления счетами и подписками пользователя без использования серверной части и облачных сервисов.

### Основной функционал

- Локальное хранение данных о счетах и подписках на устройстве пользователя
- Создание новых записей о платежах и подписках
- Редактирование существующих записей
- Удаление записей о платежах и подписках
- Поддержка категоризации расходов
- Привязка каждого платежа к одной категории

### Управление платежами и подписками

- Хранение следующих параметров платежа:
  - наименование
  - сумма платежа
  - валюта
  - тип записи (разовый платёж или подписка)
  - категория
  - дата платежа
  - периодичность (для подписок)
  - дополнительное описание (опционально)
- Отметка платежа как выполненного (для разовых счетов)

### Аналитика и обзоры

- Отображение обзора расходов за выбранный месяц
- Агрегация расходов по категориям
- Просмотр суммарных затрат за период
- Обновление аналитических данных в реальном времени при изменении записей

### Уведомления

- Локальные уведомления о предстоящих платежах
- Настройка времени напоминания до даты платежа
- Автоматическое обновление уведомлений при изменении данных платежа

### Пользовательское взаимодействие

- Просмотр списка всех платежей и подписок
- Фильтрация записей по категориям
- Удобная форма ввода и редактирования данных
- Интуитивно понятная навигация между экранами приложения

### Ограничения

- Отсутствие регистрации и аутентификации пользователей
- Отсутствие облачной синхронизации данных
- Работа приложения в рамках одного устройства
- Отсутствие интеграции с банковскими и платёжными системами
